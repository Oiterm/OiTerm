# OiTerm

네트워크 엔지니어용 Windows 터미널 — SSH · Telnet · 시리얼(콘솔) · SFTP/FTP · VNC · RDP · 웹 GUI · 로컬 셸(PowerShell/cmd/WSL)을 탭 하나로.
EVE-NG / PNETLab 노드 클릭 연동, 분할 화면·동시 입력, 위험 명령 경고, 화면의 IP·MAC 바로 Ping·조회, IP 스캔, TFTP 서버까지 들어 있습니다.

- **다운로드**: 오른쪽 [Releases](../../releases)에서 (Windows 10/11 64비트)
  - **`OiTerm-Setup-<버전>.exe`** — 설치 버전 (추천). 설치 위치를 고를 수 있고, 새 버전이 나오면 앱 안에서 버튼 한 번으로 업데이트
  - `OiTerm-<버전>-win-x64.zip` — 무설치 버전. 압축 풀고 `OiTerm.exe` 실행
- **라이선스**: MIT (`LICENSE.txt`). 함께 들어 있는 오픈소스 목록은 빌드할 때 만들어지는 `THIRD-PARTY-NOTICES.txt`
- 개인이 만들어 공유하는 프로젝트라 공식 지원은 없습니다. 코드 서명이 없어 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다.

## 이름 변경 안내 (SwitchTerm → OiTerm, 1.5.0)

- 예전 SwitchTerm에서 쓰던 세션·비밀번호·설정·최근 목록·웹 로그인은 처음 실행할 때 자동으로 옮겨집니다 (`%APPDATA%\SwitchTerm` → `%APPDATA%\OiTerm`).
- EVE-NG / PNETLab 링크 연동을 켜뒀다면 새 OiTerm.exe로 자동으로 다시 연결됩니다.
- 예전에 쓰던 로그·받은 파일·TFTP 폴더(`문서\SwitchTerm Logs` 등)는 설정에 저장된 경로 그대로 계속 씁니다.
- 예전 SwitchTerm 폴더(압축 푼 곳)는 OiTerm을 한 번 실행해서 세션이 보이는 걸 확인한 뒤 지우면 됩니다. 예전 프로그램이 켜져 있는 동안에는 옮기지 못하니 먼저 닫아주세요.

## 설치 / 실행

**설치 버전 (`OiTerm-Setup-<버전>.exe`)**
1. 실행 → "나만"(관리자 권한 필요 없음, 기본) 또는 "모든 사용자"(관리자 권한 요청) 선택.
2. 설치 위치 선택 (기본 `%LOCALAPPDATA%\Programs\OiTerm`, 원하는 폴더로 바꿀 수 있음) → 설치.
3. 바탕화면·시작 메뉴에 바로가기가 생기고, 지울 때는 **설정 → 앱** 또는 제어판 "프로그램 제거"에서.
   - 서명되지 않은 프로그램이라 처음엔 "Windows의 PC 보호" 창이 뜰 수 있습니다 → **추가 정보 → 실행**.

**무설치 버전 (zip)**
1. `OiTerm-<버전>-win-x64.zip` 압축을 아무 폴더에 풉니다 (예: `C:\Tools\OiTerm`).
2. `OiTerm.exe` 실행. 지울 때는 폴더만 지우면 됩니다.

둘 다 설정·세션 저장 위치가 같아서, zip으로 쓰다가 설치 버전으로 바꿔도 세션이 그대로 보입니다.

설정·세션은 `%APPDATA%\OiTerm\oiterm-config.json`에 저장됩니다 (비밀번호는 Windows DPAPI로 암호화).
로그는 기본적으로 `문서\OiTerm Logs`에 쌓입니다.

## 기능

| 기능 | 설명 |
|---|---|
| 로컬 셸 | Windows PowerShell / PowerShell 7 / 명령 프롬프트(cmd) / WSL / Git Bash를 탭으로 (Tabby처럼). 툴바 **로컬**, Ctrl+Shift+\`. 직접 고른 셸(.exe)·시작 폴더는 세션으로 저장 |
| 스마트 링크 | 장비 출력의 **IP·MAC·웹 주소**에 마우스를 올리면 밑줄 → **Ctrl+클릭** 또는 **오른쪽 클릭**으로 메뉴. IP: Ping(한 번/계속), Traceroute, SSH·Telnet·웹 열기, IP 스캔, `show ip arp` 입력. MAC: 제조사(OUI), `show mac address-table` 입력, 형식 바꿔 복사 |
| 위험 명령 경고 | `reload`, `write erase`, 인터페이스 `shutdown`, `add` 없는 `switchport trunk allowed vlan` 등을 Enter 전에 잡아서 확인. 줄임말(`wr er`, `rel`)도 잡고, 아주 위험한 건 **장비 이름을 쳐야** 실행. 붙여넣기·버튼·명령창·동시 입력도 검사. 규칙은 설정에서 추가/삭제 |
| 분할 화면 | 좌우 / 상하 / 세로 3분할 / 4분할(2×2) / 6분할(3×2) / 9분할(3×3). 탭을 원하는 칸에 끌어다 놓기, 칸을 누르면 그 탭이 선택됨 |
| 동시 입력 | 키보드로 치는 내용을 **분할 화면에 보이는 탭** 또는 **연결된 모든 탭**에 똑같이 입력 (주황색 띠로 표시, 탭 메뉴에서 특정 탭 제외 가능). 붙여넣기도 같이 들어감 |
| VNC | 탭 안에서 VNC 화면 보기 (EVE-NG / PNETLab GUI 노드). Ctrl+Alt+Del, 클립보드 보내기, 클립보드 내용을 키보드로 입력, 화면 맞춤, 보기 전용 |
| SFTP / FTP / FTPS | 파일 전송 탭: 폴더 탐색, 올리기(탐색기에서 끌어다 놓기), 받기, 새 폴더, 이름 바꾸기, 삭제, 진행률. SSH 탭 메뉴에서 "SFTP 파일 창 열기" |
| ZMODEM | 장비에서 `sz 파일` → 받기 확인 후 자동 저장, `rz` → 보낼 파일 선택창. 진행률·취소 (Ctrl+C) |
| XMODEM / YMODEM | 콘솔로 펌웨어 올리기 (ROMMON / 부트로더 복구). XMODEM-1K, XMODEM, YMODEM |
| TFTP 서버 | 장비 설정 백업(`copy run tftp:`)·이미지 받기용. 폴더 지정, 방향별 허용, 자동 중지, PC IP와 명령 복사 |
| IP 스캔 | 대역(`192.168.0.0/24`, `10.1.1.1-50` 등) 안의 살아있는 장비 찾기: 핑 응답·TTL, 열린 포트(SSH/Telnet/웹/RDP 등), 이름(DNS), MAC·제조사, SSH/Telnet 배너. 포트를 누르면 바로 접속, 세션으로 저장, CSV(엑셀) 저장 |
| 웹 GUI (HTTP/HTTPS) | 방화벽·스위치 관리 웹화면을 탭 안에서. 주소창, 뒤로/앞으로, 새로고침, 페이지 찾기, 확대, 자체 서명 인증서 확인, HTTP 기본 인증 자동, "로그인 정보 입력" 버튼, 팝업은 새 탭, 다운로드는 받은 파일 폴더로, "브라우저로 열기" |
| RDP | Windows 원격 데스크톱(mstsc) 창으로 열기. 화면 크기, 클립보드·드라이브 공유, 관리자 세션, 저장한 비밀번호로 자동 로그인 |
| SSH | 비밀번호 / keyboard-interactive / 개인 키. 구형 장비용 알고리즘(diffie-hellman-group1/14-sha1, aes-cbc, 3des-cbc, ssh-dss)까지 지원. 호스트 키 확인·저장, 키가 바뀌면 경고 |
| Telnet | 옵션 협상(ECHO, SGA, 터미널 타입, 창 크기 NAWS), Keepalive |
| 시리얼 | COM 포트 자동 감지, 속도/데이터/패리티/정지 비트/흐름 제어, **Break 신호** (시스코 비밀번호 복구 등) |
| 자동 로그인 | Telnet·시리얼에서 `Username:` / `login:` / `Password:` 프롬프트를 보고 대신 입력. 실패하면 반복하지 않고 멈춤 |
| enable 자동 진입 | `Switch>` 가 보이면 `enable` + 비밀번호 입력. enable 명령어도 바꿀 수 있음 |
| 세션 관리 | 폴더(`고객사A/본관`처럼 `/`로 하위 폴더), 검색, 복제, 폴더째 한 번에 연결 |
| SecureCRT 가져오기 | `%APPDATA%\VanDyke\Config\Sessions` 폴더를 고르면 호스트/포트/아이디/시리얼 설정을 가져옴 (비밀번호 제외) |
| 탭 | 드래그로 순서 변경, 탭 복제(같은 장비 하나 더), 끊기면 Enter로 재연결, 더블클릭으로 이름 변경 |
| 로그 | 세션마다 자동 저장, 색상 코드·`--More--` 지우기 등은 정리된 텍스트로 저장. 줄마다 시간 기록은 설정에서 켜고 끔. **콘솔·IP로 바로 접속한 탭은 프롬프트의 호스트 이름으로 파일 이름**(SW1_날짜_시간.log), 콘솔 케이블을 다른 장비로 옮기면 새 파일 |
| 버튼바 | 자주 쓰는 명령 버튼. 클릭 = 현재 탭, **Shift+클릭 = 연결된 모든 탭** |
| 명령창 | 여러 줄 명령을 현재 탭 또는 모든 탭에 동시에 전송. **줄 간격**(0ms~1초)과 **프롬프트 기다리기**(장비가 SW1# 을 다시 띄워야 다음 줄)로 콘솔·느린 장비에서 줄 씹힘 방지 |
| 키워드 색칠 | down / err-disabled / notconnect / `%LINK-3-UPDOWN` 같은 키워드 색 표시. 설정에서 정규식으로 편집 |
| 붙여넣기 보호 | 여러 줄 붙여넣기 전 확인창, 줄 간격(ms) 조절로 콘솔 버퍼 넘침 방지 |
| 한글 | 장비별 UTF-8 / EUC-KR(CP949) 선택 |
| 찾기 | 스크롤백 전체 검색, 대소문자/정규식 |

## EVE-NG / PNETLab 연동

랩 웹 화면에서 노드를 클릭하면 OiTerm에 탭으로 열립니다. 이미 켜져 있으면 새 창 없이 탭만 추가돼요.
- 콘솔 노드(telnet://) → 터미널 탭
- GUI 노드(vnc://) → VNC 탭 (노드 이름이 탭 이름으로)
- Windows 노드(rdp://) → 원격 데스크톱 창

1. OiTerm **설정 → EVE-NG / PNETLab 연동** 에서 연결할 종류(telnet / vnc / rdp)를 체크하고 **"선택한 링크를 OiTerm으로 열기"** 클릭
   - 관리자 권한 없이 현재 사용자 레지스트리(HKCU)에만 등록합니다. "등록 해제"를 누르면 원래 쓰던 프로그램(PuTTY 등)으로 돌아갑니다.
   - 상태가 "거의 다 됨"으로 나오면 Windows가 기존 프로그램을 우선하고 있는 것이니 **Windows 기본 앱 설정 열기 → 링크 유형별 기본값 → TELNET → OiTerm**을 고르세요.
2. EVE-NG / PNETLab 로그인 화면에서 콘솔을 **Native Console(Default Console)** 로 선택
3. 노드를 클릭했을 때 브라우저가 "OiTerm 열기"를 물으면 **항상 허용** 체크
4. 설정의 "테스트" 버튼으로 연결이 되는지 확인할 수 있습니다 (새 탭이 생기면 성공).

**탭 이름**
- 랩이 콘솔 접속 때 보내주는 노드 이름(터미널 제목)을 탭 이름으로 씁니다. (SuperPuTTY가 IP로만 보여주는 그 부분)
- 노드 이름이 안 오면 프롬프트의 호스트 이름을 씁니다. `SW1#` → `SW1`. 랩에서 `hostname`을 바꾸면 탭 이름도 따라 바뀝니다.
- 탭을 더블클릭해서 직접 이름을 바꾸면 그 이름이 유지됩니다.
- 로그 파일 이름도 같은 이름으로 저장됩니다 (`SW1_20261029_110512.log`).
- 링크로 열면 접속 후 Enter를 한 번 보내 프롬프트를 바로 띄웁니다 (설정에서 끌 수 있음).

## 분할 화면 / 동시 입력

- 툴바 **분할** → 좌우 2분할, 상하 2분할, 세로 3분할, 4분할(2×2), 6분할(3×2), 9분할(3×3). 칸이 많을 땐 Ctrl+마우스 휠로 글자 크기를 줄이면 보기 편합니다. 다시 "한 화면"으로 돌아갈 수 있습니다.
- 위의 탭을 원하는 칸으로 끌어다 놓으면 그 칸에 표시됩니다. 탭 메뉴(오른쪽 클릭)의 "○ 칸에 표시"도 같은 기능.
- 툴바 **동시 입력** → "분할 화면에 보이는 탭" 또는 "연결된 모든 탭". 켜져 있는 동안 위에 주황색 띠와 대상 탭 목록이 보입니다.
- 특정 장비만 빼려면 그 탭 메뉴에서 **동시 입력에서 제외**.
- 여러 줄 명령을 한 번에 보내는 건 기존 **명령창**(Ctrl+Shift+M)도 계속 쓸 수 있습니다.

## 파일 전송 (SFTP / FTP)

- 새 세션에서 프로토콜을 SFTP 또는 FTP로 고르거나, SSH 탭 메뉴에서 **SFTP 파일 창 열기**.
- 탐색기에서 파일·폴더를 끌어다 놓으면 지금 보고 있는 원격 폴더로 올라갑니다.
- 받기는 처음 한 번 받을 폴더를 고르고, 그다음부터는 같은 폴더로 받습니다 (메뉴의 "받을 폴더 골라서 받기"로 변경).
- 단축키: Enter 열기, Backspace 상위 폴더, F2 이름 바꾸기, Delete 삭제, F5 새로고침, Ctrl+A 모두 선택.
- 시스코 IOS 등 일부 장비는 SFTP 서버가 없고 SCP만 됩니다.

## 웹 GUI (HTTP / HTTPS)

- 새 세션 → 프로토콜 **웹** → 방식(HTTPS/HTTP), 주소, 포트, 경로. 빠른 연결도 됩니다.
- 장비가 자체 서명 인증서를 쓰면 처음 한 번 인증서 지문을 보여주고 허용할지 묻습니다. "허용하고 저장"하면 다음부터는 묻지 않고, 인증서가 바뀌면 경고합니다.
- 아이디/비밀번호를 세션에 저장해두면:
  - HTTP 기본 인증(브라우저 로그인 창이 뜨는 방식)은 자동으로 로그인
  - 로그인 화면이 있는 장비는 **로그인 정보 입력** 버튼으로 칸을 채움 (지금 페이지 주소가 세션 주소와 같을 때만)
- 새 창으로 열리는 링크는 OiTerm 새 탭으로 열립니다. 분할 화면에 터미널과 웹 화면을 같이 띄울 수 있어요.
- 다운로드(설정 백업 등)는 받은 파일 폴더(기본 `다운로드\OiTerm`)에 저장됩니다.
- 단축키: F5 새로고침, Ctrl+L 주소창, Ctrl+F 찾기, Alt+←/→ 뒤로/앞으로, Ctrl+= / - / 0 확대.
- 아주 오래된 장비가 TLS 1.0/1.1만 지원하면 최신 엔진으로는 HTTPS가 열리지 않습니다 (크롬·엣지도 마찬가지). 이럴 땐 HTTP로 접속하거나 펌웨어를 업데이트해야 합니다. Java 애플릿·플래시 기반 화면도 열 수 없습니다.
- 웹 탭의 쿠키·로그인 상태는 앱과 분리된 공간에 저장되고, 설정 → "웹 로그인·쿠키 지우기"로 한 번에 지울 수 있습니다.

## 터미널 파일 전송 (ZMODEM / XMODEM / YMODEM)

- **ZMODEM**: 장비에서 `sz 파일이름`을 치면 받을지 물어본 뒤 받은 파일 폴더(기본: `다운로드\OiTerm`)에 저장합니다. `rz`를 치면 보낼 파일을 고르는 창이 뜹니다. 전송 중 Ctrl+C 또는 "취소"로 중단.
- **XMODEM / YMODEM**: 장비에서 받기 명령(예: ROMMON의 `xmodem`, 부트로더의 `copy xmodem: flash:`)을 먼저 실행하고, 화면에 `C`가 찍히기 시작하면 툴바 **보내기** → 파일과 방식 선택.
- 9600bps 콘솔은 매우 느립니다. 가능하면 장비와 세션 속도를 115200으로 올리고 보내세요.

## TFTP 서버

- 툴바 **TFTP** → 폴더 확인 → **서버 시작**. 화면에 나오는 이 PC의 IP를 장비 명령에 넣습니다.
  - 백업: `copy running-config tftp://<PC IP>/SW1-confg`
  - 받기: `copy tftp://<PC IP>/<이미지 파일> flash:`
- "PC → 장비", "장비 → PC" 방향을 각각 켜고 끌 수 있고, 일정 시간 전송이 없으면 자동으로 멈춥니다.
- 처음 시작할 때 Windows 방화벽이 물으면 **개인 네트워크만** 허용하세요. UDP 69를 다른 TFTP 서버(tftpd64 등)가 쓰고 있으면 시작되지 않습니다.
- TFTP는 암호·인증이 없는 프로토콜입니다. 쓸 때만 켜두세요.

## IP 스캔

- 툴바 **IP 스캔** → 대역 입력(또는 "내 네트워크"에서 고르기) → **스캔 시작**.
  - 적는 법: `192.168.0.0/24`, `10.1.1.1-50`, `10.1.1.1-10.1.2.254`, 여러 개는 쉼표. 한 번에 최대 4096개(/20).
- 표에 나오는 것: 응답 방식(핑/TCP), 응답 시간, TTL(64 리눅스 기반 / 128 Windows / 255 Cisco IOS 등), 이름(DNS), MAC·제조사(같은 대역일 때만), 열린 포트, 배너(`SSH-2.0-Cisco-1.25` 등).
- 포트 칸의 버튼을 누르면 바로 접속(22 SSH, 23 Telnet, 80/443/8080/8443 웹 탭, 3389 RDP, 5900 VNC). 줄을 두 번 누르면 SSH → Telnet → 웹 순서로 열려 있는 것에 접속.
- 우클릭: 접속 방식 고르기, **세션으로 저장**, IP 복사, 보이는 IP 전부 복사.
- 세션·탭 우클릭 메뉴의 **같은 대역 IP 스캔 (/24)** 으로 그 장비 대역을 바로 스캔.
- 방화벽이 핑을 막는 망이면 **핑 없어도 포트 확인**을 켜세요(느려짐).
- **주의**: 고객사 망에서는 방화벽·IPS가 스캔을 공격으로 보고 차단하거나 경보를 낼 수 있습니다. 허락받은 대역만, 동시 수는 낮게. 사설 IP가 아닌 주소가 들어 있으면 한 번 더 확인을 받습니다.

## 스마트 링크 (화면의 IP · MAC)

- 장비 출력(`show ip route`, `show arp`, 방화벽 로그 등)에 나온 **IP / MAC / http(s) 주소**에 마우스를 올리면 밑줄이 생깁니다.
- **Ctrl+클릭** 또는 **오른쪽 클릭**(붙여넣기 모드여도 밑줄 위에서는 메뉴)으로:
  - IP: **Ping**(4번 / 멈출 때까지), **Traceroute** — 이 PC에서 실행, 결과는 아래 도구 창 / SSH·Telnet·웹으로 새 탭 / **IP 스캔**(그 IP 바로, 또는 /24 대역) / 장비에 `show ip arp <IP>` 입력
  - MAC: **제조사**(IEEE OUI — Cisco, Allied Telesis, Alcatel-Lucent 등) / 장비에 `show mac address-table address <MAC>` 입력 / 시스코(aabb.ccdd.eeff)·콜론·하이픈 형식으로 복사
- 인식하는 MAC 형식: `aabb.ccdd.eeff`(Cisco), `aa:bb:cc:dd:ee:ff`, `aa-bb-cc-dd-ee-ff`(Windows), `aabb-ccdd-eeff`(Huawei/H3C)
- "장비에 입력"은 명령을 쳐 주기만 하고 **Enter는 누르지 않습니다**. 벤더별 명령은 설정 → 스마트 링크에서 바꿀 수 있습니다 (예: 얼라이드 `show mac address-table | include {mac}`).

## 위험 명령 경고

- Enter를 누르는 순간 지금 줄의 명령을 확인합니다. 장비 화면의 줄(히스토리로 불러온 것 포함)과 직접 친 글자를 둘 다 봐서, 장비 echo가 늦어도 잡습니다.
- 단계
  - **확인**: "실행" 버튼을 눌러야 보냄. 이때 Enter는 **취소**라서 Enter를 연타해도 실행되지 않음 (예: 인터페이스 `shutdown`)
  - **장비 이름 입력**: 프롬프트의 장비 이름(SW1# → `SW1`)을 그대로 쳐야 실행 버튼이 켜짐 (예: `reload`, `write erase`)
  - **차단**: 아예 보내지 않음
- 기본 규칙: reload / write erase / erase startup-config / format / configure replace / reboot / delete / 인터페이스 모드 shutdown / add 없는 switchport trunk allowed vlan / default interface / no router / no vlan / no interface / no spanning-tree / clear ip bgp / FortiGate·Juniper·Huawei 재부팅·초기화 / 리눅스 rm -r·mkfs·dd·shutdown / Windows 폴더째 삭제·재시작
- 줄임말도 잡습니다 (`wr er`, `era st`, `rel`, `shut`). `reload cancel`은 제외. 설정 모드의 `do wr er`도 잡습니다.
- 여러 줄(붙여넣기·버튼·명령창)은 `conf t` → `interface` → `end` 흐름을 따라가며 몇 번째 줄이 위험한지 보여줍니다.
- 동시 입력 중이면 몇 대에 같이 들어가는지 창에 크게 표시합니다.
- 설정 → 위험 명령 경고에서 규칙 추가·삭제·단계 변경. 랩 장비 탭은 탭 우클릭 → "위험 명령 경고 끄기 (이 탭만)".
- 안전망이지 보증은 아닙니다: 시스코가 긴 줄을 `$`로 줄여 보여주는 상태에서 히스토리로 불러온 명령처럼 화면과 입력 둘 다 확인할 수 없는 경우는 놓칠 수 있습니다.

## 로컬 셸

- 툴바 **로컬** → PowerShell / PowerShell 7 / cmd / WSL / Git Bash 중 이 PC에 있는 것. **Ctrl+Shift+\`** 는 기본 셸(설정에서 변경).
- 장비 탭과 똑같이 분할 화면·로그·찾기·스마트 링크(ipconfig, arp -a 결과의 IP·MAC)·위험 명령 경고가 됩니다.
- 다른 셸(.exe)이나 시작 폴더를 쓰려면 새 세션 → 프로토콜 "로컬 셸".
- 탭을 닫으면 셸과 그 안에서 돌던 프로그램(ping -t 등)까지 같이 끝납니다.
- 로그는 기본으로 저장하지 않습니다 (설정 → 로컬 셸에서 켜기).

## 명령창 줄 간격 / 프롬프트 기다리기

- 명령창(Ctrl+Shift+M) 오른쪽에서 **줄 간격**(0ms~1초)을 고르면 한 줄 보내고 그만큼 쉽니다. "설정값"은 설정 → 붙여넣기의 줄 간격.
- **프롬프트 기다리기**를 켜면 장비가 `SW1(config-if)#` 같은 프롬프트를 다시 띄운 뒤에 다음 줄을 보냅니다. 9600 콘솔이나 느린 스위치에 긴 설정을 넣을 때 줄이 씹히지 않습니다. 15초 동안 프롬프트가 안 나오면 멈추고 몇 번째 줄에서 멈췄는지 알려줍니다.
- 키워드 색칠(up·connected 초록, down·err-disabled·fail 빨강 등)은 설정 → 키워드 색칠에서 바꿉니다.

## 자동 업데이트

- 하루 한 번(켜져 있을 때) GitHub 릴리즈에서 새 버전을 확인하고, 있으면 오른쪽 아래에 알림이 뜹니다. **설정 → 업데이트**에서 끄거나 "지금 확인".
- **설치 버전**: "업데이트" → 받아서 확인 → 조용히 설치 → OiTerm이 다시 켜짐 (설치 위치·설정 그대로). 연결된 탭은 끊기니 작업 중이면 나중에.
- **zip 버전**: 다운로드 페이지만 열어줍니다 (새 zip을 받아 같은 폴더에 덮어쓰기).
- 안전장치: 업데이트 정보(`latest.json`)는 OiTerm 서명 키(Ed25519)로 서명되어 있고, 앱에 들어 있는 공개 키로 확인합니다. 서명이 안 맞거나, 받은 설치 파일의 SHA-512·크기가 서명된 값과 다르거나, 지금보다 낮은 버전이면 설치하지 않습니다. github.com 주소만 접속하고, 다른 곳으로 넘기려 하면 멈춥니다. 보내는 정보는 없습니다(버전이 적힌 User-Agent뿐).
- 인터넷이 막힌 폐쇄망에서는 설정에서 꺼두세요.

## 보안

이 프로그램이 지키는 것:
- 저장된 비밀번호는 Windows DPAPI로 암호화 (`%APPDATA%\OiTerm`). 백업 내보내기에는 비밀번호가 빠집니다.
- SSH 호스트 키 확인 (처음 접속 시 지문 확인, 바뀌면 경고).
- 화면(웹 부분)은 Node 권한이 없는 샌드박스에서 돌고, 메인 프로세스 기능은 정해진 통로로만 호출 (보낸 창이 우리 창인지 확인).
- 외부 링크는 http/https만 브라우저로 열고, 장비 출력 속 링크는 확인 후 열기. 새 창·페이지 이동·카메라/마이크 등 권한 요청은 모두 차단.
- 웹 페이지가 telnet:// vnc:// rdp:// 링크로 사설 IP가 아닌 주소에 접속시키려 하면 확인을 받습니다.
- 받는 파일(ZMODEM·SFTP·FTP) 이름에서 `..` 같은 경로를 지우고, 같은 이름이 있으면 덮어쓰지 않고 번호를 붙입니다. TFTP는 지정한 폴더 밖으로 못 나갑니다.
- VNC 중계는 127.0.0.1에서만, 한 번 쓰는 토큰으로만 열립니다. 웹 페이지(다른 출처)에서 오는 연결은 거절합니다.
- 웹 GUI 탭은 Node 권한·preload 없이 샌드박스로만 열리고(화면 쪽에서 어떤 설정을 넘겨도 메인 프로세스가 강제로 덮어씀), 쿠키·저장소는 앱과 분리된 별도 세션을 씁니다. http/https 외의 주소(file:, ms-* 등)로의 이동·요청은 차단, 위치·알림·카메라 등 권한은 거절, 인증서 오류는 사용자가 지문을 보고 허용해야만 진행합니다.
- 저장된 웹 비밀번호는 페이지로 자동 전송되지 않습니다. 기본 인증은 세션에 적힌 장비 주소에만 한 번, 로그인 칸 채우기는 버튼을 눌렀을 때 같은 주소의 페이지에만.
- IP 스캔은 입력한 대역을 숫자로 바꾼 뒤 다시 만든 주소만 쓰고, ping·arp는 Windows System32의 절대 경로로 셸 없이 실행합니다. 장비가 보낸 이름·배너는 글자로만 표시하고, CSV로 저장할 때 `=` `+` `-` `@`로 시작하는 칸은 엑셀 수식으로 실행되지 않게 막습니다.
- 로컬 셸은 정해진 셸(System32의 PowerShell·cmd·WSL, Program Files의 PowerShell 7·Git Bash)이나 사용자가 고른 절대 경로 .exe만 실행하고, 인자는 넘기지 않습니다. 웹 페이지·EVE 링크로는 로컬 셸을 열 수 없습니다. 셸에는 Electron/Node 관련 환경 변수를 넘기지 않습니다.
- 스마트 링크의 Ping/Traceroute는 화면에서 찾은 IP를 숫자로 검사한 뒤 System32의 ping/tracert를 셸 없이 실행합니다 (동시 4개, 계속 핑은 최대 1시간). URL은 http/https만 인식합니다.
- 자동 업데이트는 서명(Ed25519)·SHA-512가 모두 맞는 설치 파일만 실행 (위 "자동 업데이트" 참고).
- 배포 파일은 Electron 보안 퓨즈 적용 (ELECTRON_RUN_AS_NODE, NODE_OPTIONS, 디버거 인자 차단, asar 무결성 검사).

알고 쓰셔야 하는 것:
- Telnet, FTP, TFTP, VNC(대부분)는 원래 암호화가 없는 프로토콜입니다. 운영망에서는 SSH/SFTP를 쓰세요.
- FTPS는 장비의 자체 서명 인증서를 받아들이도록 인증서 검증을 하지 않습니다.
- 로그 파일은 평문입니다. `show run`에 들어간 비밀번호 해시 등도 그대로 남습니다.
- RDP 비밀번호를 저장해두면 Windows 자격 증명 관리자에도 저장됩니다 (`TERMSRV/호스트`).
- 코드 서명이 안 된 프로그램이라 Windows가 경고를 띄웁니다.

## 마우스

- 드래그로 선택하면 바로 복사됨 (설정에서 끌 수 있음)
- 오른쪽 클릭 = 붙여넣기, **Shift+오른쪽 클릭** = 메뉴
- 밑줄 친 IP·MAC·주소 위에서 **오른쪽 클릭** 또는 **Ctrl+클릭** = 스마트 메뉴 (Ping, 접속, 스캔, 제조사)
- 가운데 클릭 = 붙여넣기
- Ctrl + 휠 = 글자 크기

## 문제 해결

- **한글이 깨짐** → 세션 편집 → 고급 → 문자 인코딩을 EUC-KR로.
- **SSH가 "알고리즘 협상 실패"로 안 붙음** → 장비가 아주 오래된 방식만 지원하는 경우. 오류 메시지에 장비가 제시한 알고리즘이 나오니 그걸 알려주면 추가할 수 있습니다.
- **지울 때 `^H`나 이상한 글자가 찍힘** → 세션 편집 → 고급 → Backspace 키를 Ctrl+H로.
- **COM 포트가 안 보임** → USB 콘솔 케이블 드라이버(Prolific, FTDI, CH340 등) 확인. 장치 관리자에 COM 번호가 떠야 합니다. 직접 `COM3`처럼 입력해도 됩니다.
- **긴 설정을 콘솔에 붙여넣으면 글자가 빠짐** → 설정 → 줄 간격을 100~300ms로.
- **유휴 상태로 두면 끊김** → 세션 편집 → Keepalive 30~60초.

## 소스에서 실행 / 직접 빌드

Node.js 20 이상 필요.

```
npm install
npm start               # 개발 모드로 실행
npm run dist:win        # 오픈소스 고지 만들고 dist\OiTerm-<버전>-win-x64.zip 생성
npm run dist:win-installer   # 설치 파일(.exe) 생성
npm run dist:release    # 설치 파일 + zip
```

릴리즈는 GitHub **Actions 탭 → release → Run workflow**(package.json 버전으로 `v<버전>` 태그를 만듦) 또는 `v2.0.0` 같은 태그를 올리면 GitHub Actions(`.github/workflows/release.yml`)가 Windows에서 빌드하고, 저장소 Secrets의 `OITERM_UPDATE_KEY`로 `latest.json`을 서명해서 Releases에 올립니다. 변경 내용은 `CHANGELOG.md`의 해당 버전 부분이 그대로 쓰입니다.
